## Public Summary

PromptVault is a local Windows desktop application for organizing, searching, and reusing AI prompts without depending on external accounts or services. It provides a dark WPF interface, prompt cards, categories, tags, recommended models, favorites, search, variables, usage counters, and JSON import/export.
